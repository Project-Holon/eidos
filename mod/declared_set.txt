# mod/declared_set.txt -- the hookable set: the game functions the port
# routes through a slot (docs/mod-interface.md, sections 1 and 2).  A mod can
# reach a game function only when it is listed here.  tools/bootlink.py reads
# the arm9 rows and tools/ovlink.py the overlay rows; each emits one slot per
# row.  With no mod installed a slot calls the original.
#
# One row per function, tab separated:
#   address   the even function start, as aletheia's manifests spell it
#   function  the aletheia function name
#   region    arm9, or the overlay id; two overlays can share one address,
#             so the region is part of the key
#   events    the stable events the port binds to this function, comma
#             separated (docs/mod-events.md, section 1).  Empty: the row is a
#             raw hook only (docs/mod-events.md, section 5).
#
# `#` starts a comment.  Every row is checked against aletheia's per-packet
# manifests (layout/matched/**/pkt_*.json) by address, name and region.
